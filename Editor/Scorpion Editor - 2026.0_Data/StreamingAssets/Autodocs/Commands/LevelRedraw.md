### LevelRedraw

**Category:**
Level

**Syntax:**

```scorpionengine
LevelRedraw Width=Expression Height=Expression X=Expression Y=Expression
```

**Description:**

Redraw a rectangular area of the level in place

Width: The box width
Height: The box height
X: The X coordinate
Y: The Y coordinate

```scorpionengine

LevelRedraw Width=1 Height=1 X=1 Y=1

```
