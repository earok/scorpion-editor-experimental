### PanelSpecial

**Category:**
Display

**Syntax:**

```scorpionengine
PanelSpecial PanelSpecial Cache
```

**Description:**

Change the 32X panel OR Amiga Sprite Panel

Panel: The special panel
Cache: Optional cache type cache/cachelock/cacheunlock/cacheunload

```scorpionengine

PanelSpecial MyPanel cache

```
