### StringLookupTable

**Category:**
Variable

**Syntax:**

```scorpionengine
StringLookupTable VarName "FileName"
```

**Description:**

LookUpTable of strings, one per line or Key=Value.

VarName: The variable name
FileName: The relative file path

```scorpionengine

StringLookupTable MyVariable "MyFile.txt"

```
