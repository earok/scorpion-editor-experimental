### Decal

**Category:**
Level

**Syntax:**

```scorpionengine
Decal Animation X=Expression Y=Expression Frame=Expression
```

**Description:**

Paint a single animation frame into the level

Animation: The animation to play
X: The X coordinate
Y: The Y coordinate
Frame: The first frame

```scorpionengine

Decal MyAnimation X=1 Y=1 Frame=1

```
