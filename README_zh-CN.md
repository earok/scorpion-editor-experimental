Scorpion Engine旨在成为一款快速、易用且灵活的游戏开发工具包，适用于Commodore Amiga、Sega Mega Drive/Genesis以及SNK NeoGeo平台。

这是Scorpion Engine 2024.1的实验版本，它拥有最新最强大的功能，但尚未经过充分测试。

建议您使用[主仓库](https://github.com/earok/scorpion-editor-demos)，该版本经过了更全面的测试，既适合刚开始学习这款引擎的新手，也适合即将完成最终作品的经验丰富的开发者。那里还有更多详细信息，包括所有演示中使用的素材致谢内容。
