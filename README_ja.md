Scorpion Engineは、Commodore Amiga、Sega Mega Drive/Genesis、SNK NeoGeo向けの、高速で使いやすく柔軟性に優れたゲーム制作キットとして開発されました。

これはScorpion Engine 2024.1の試験版であり、最新かつ最強の機能が搭載されていますが、まだ十分なテストは行われていません。

より徹底的にテストが行われており、エンジンの使い方を学び始める初心者の開発者から、最終版のゲーム開発に取り組む経験豊富な開発者まで幅広く推奨されている[メインリポジトリ](https://github.com/earok/scorpion-editor-demos)の利用もご検討ください。また、すべてのデモで使用されているアセットへの謝辞を含む詳細情報もそちらで確認できます。

[Patreon](https://patreon.com/scorpionengine)で私たちを応援していただけると幸いです。
